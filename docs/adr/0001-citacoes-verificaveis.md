# Citações verificáveis

A mesa responde com trechos recuperados do dossiê. A citação guarda o arquivo, a posição no texto e o conteúdo que o índice devolveu. O texto da citação não é extraído da frase do modelo.

Se nenhum trecho estiver perto da pergunta, a resposta é fixa: o dossiê não cobre a pergunta. Nesse caminho o modelo de chat não é chamado.

Dois trechos próximos e contraditórios são os dois devolvidos. O prompt pede para mostrar os dois, sem eleger um vencedor.
